# hyprland-rust gaps for the OsmiumOS desktop

OsmiumOS ships `hyprland-rust` (origin/main `f0ce131`) as its compositor and
`end-4/dots-hyprland` at `2f2a376f` as the default desktop: the `ii` Quickshell
shell, its `waffle` (Windows 11) panel family, and the archived `m3ww` EWW style.
This file lists everything the compositor still lacks for that desktop, the
installer (Quickshell `FloatingWindow`) and the live-ISO panel (Quickshell
`PanelWindow`). It was written to be worked through item by item. Item numbers
are kept from the `d9010fb` revision; finished items are in the last list.

Method. Every item was re-checked at `f0ce131` against `hyprland-rust/src/**`
by reading the code path (is the global registered and its requests handled, is
the option parsed and used), not against `docs/PARITY.md` or `CLAUDE.md`, which
lag behind. Consumers were read at the pinned dots commit: `dots/.config/quickshell/ii/**`,
`dots/.config/hypr/**`, branch `archive` `m3ww/**`, and Quickshell's own sources.
Nothing was run: this machine is Windows and the compositor needs Linux.
"unverified" marks what I could only read.

Paths: `src/...` is `hyprland-rust/src/...`; `ii/...` is
`dots/.config/quickshell/ii/...`; `hypr/...` is `dots/.config/hypr/...`;
`m3ww/...` is `m3ww/.config/...` on branch `archive`.

Status words: **missing** (not present), **partial** (present, say what is
not), **not rendered** (parsed or stored, never drawn or applied), **unverified**.

Count at `f0ce131` (47 items): 19 done, 14 partial, 14 missing.

Reading order: tier A blocks a feature or the whole session, tier B degrades
behaviour, tier C is visual only. Inside a tier the order is by impact.
